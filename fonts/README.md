# Bundled fonts

TeX Gyre Heros, a free Helvetica clone, so the templates render the
same on every machine and in CI. The typst.app web app has it built in.
Locally, compile with `--font-path fonts` in this repo, or install the
fonts on your system.

`texgyreheros-*.otf` are the regular, italic, bold, and bold-italic
weights of TeX Gyre Heros 2.609, maintained by the Polish TeX Users
Group (GUST). Upstream:
https://www.gust.org.pl/projects/e-foundry/tex-gyre/heros
